> ⚠️ **Region Reminder:** All AWS integrations should use the **us-west-2 (Oregon)** region.

**Estimated Time:** 40 minutes

**Objective:** Set up your autobotAI account and establish secure integrations with AWS services to enable intelligent security automation.

## Module Overview

In this module, you will:

1. **Create your autobotAI account** with secure authentication (MFA)
2. **Activate your workshop subscription** using a coupon code
3. **Set up AWS integrations** for infrastructure, AI, and notifications
4. **Configure GitHub integration** for code security automation

By the end of this module, you'll have a fully configured autobotAI platform ready to deploy intelligent security agents.

---

## Module Sections

### 1.1 Signing Up on autobotAI Platform
Create your account, set up multi-factor authentication, and activate your subscription using the provided coupon code.

### 1.2 Adding AWS Integration
Set up AWS, Amazon Bedrock, Amazon Athena, and Amazon SES integrations to enable comprehensive security automation:
- **AWS Integration**: Infrastructure access and security service integration
- **Amazon Bedrock Integration**: AI-powered threat analysis and response generation
- **Amazon Athena Integration**: SQL query engine for log analytics (powers the WAF Log Threat Analysis in Module 2)
- **Amazon SES Integration**: Automated security notifications and alerts

### 1.3 Adding GitHub and AbuseIPDB Integrations
Connect your GitHub repositories for AI-driven code analysis and set up threat intelligence integration for malicious IP validation. Also configure global AI settings for the platform.
